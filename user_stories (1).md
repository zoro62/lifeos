# LifeOS — User Stories & MoSCoW Prioritization

Format: `As a [user], I want to [action], so that [benefit].`
Each story is tagged for direct use as a GitHub Issue (title + priority label).

## Must Have (MVP — Version 1)

1. **Account Registration** — As a new user, I want to sign up with email/password or Google, so that I can create a secure personal account.
   `Priority: Must`
2. **Login** — As a returning user, I want to log in with fingerprint after my first password login, so that daily access is fast and seamless.
   `Priority: Must`
3. **Multi-Account Switching** — As a user sharing a device, I want to switch between accounts, so that my data stays isolated from others.
   `Priority: Must`
4. **Dashboard Overview** — As a user, I want to see today's tasks, habits, and goals on one dashboard, so that I don't have to open multiple apps.
   `Priority: Must`
5. **Create Task** — As a user, I want to create a task with a due date and priority, so that I can track what needs to get done.
   `Priority: Must`
6. **Nested Subtasks** — As a user, I want to break a task into subtasks, so that I can manage complex work step by step.
   `Priority: Must`
7. **Recurring Tasks** — As a user, I want to mark a task as recurring, so that I don't have to recreate routine tasks manually.
   `Priority: Must`
8. **Create Note** — As a user, I want to write and save a note, so that I can capture information quickly.
   `Priority: Must`
9. **Create Habit** — As a user, I want to define a daily habit, so that I can track consistency over time.
   `Priority: Must`
10. **Habit Streak Tracking** — As a user, I want to see my current streak for a habit, so that I stay motivated to continue.
    `Priority: Must`
11. **Create Counter** — As a user, I want to create a custom counter (e.g., pushups, books read), so that I can track anything important to me.
    `Priority: Must`
12. **Increment Counter** — As a user, I want to increment a counter with one tap, so that logging is effortless.
    `Priority: Must`
13. **Create Goal** — As a user, I want to set a goal with a target and deadline, so that I can work toward something concrete.
    `Priority: Must`
14. **Goal Progress Tracking** — As a user, I want my goal's progress bar to update automatically, so that I can see how close I am to completion.
    `Priority: Must`
15. **Cloud Sync** — As a user, I want my data synced to the cloud, so that I don't lose it if I change phones.
    `Priority: Must`

## Should Have (Phase 2)

16. **Journal Entry** — As a user, I want to write a daily journal entry with mood tracking, so that I can reflect on my day.
    `Priority: Should`
17. **Expense Logging** — As a user, I want to log an expense with a category, so that I can track where my money goes.
    `Priority: Should`
18. **Document Vault Upload** — As a user, I want to securely store a document (e.g., ID, certificate), so that I can access it anytime without carrying paper copies.
    `Priority: Should`
19. **Password Vault Entry** — As a user, I want to store a password with AES encryption, so that my credentials are safe and accessible.
    `Priority: Should`
20. **AI Weekly Summary** — As a user, I want an AI-generated weekly summary of my tasks and habits, so that I can understand my patterns without manual review.
    `Priority: Should`
21. **Kanban Board View** — As a user, I want to view my tasks in a Kanban board, so that I can visualize progress across stages.
    `Priority: Should`

## Could Have (Phase 3+)

22. **Google Calendar Sync** — As a user, I want my LifeOS calendar synced with Google Calendar, so that I have one unified schedule.
    `Priority: Could`
23. **Receipt OCR Scanning** — As a user, I want to scan a receipt and auto-fill an expense entry, so that logging expenses takes seconds.
    `Priority: Could`
24. **Automation Rules** — As a user, I want to create a rule like "workout completed → increase gym counter → mark habit done," so that repetitive updates happen automatically.
    `Priority: Could`

## Won't Have (This Release)

25. **Smartwatch Sync** — As a user, I want my fitness data synced from a smartwatch, so that I don't have to log workouts manually.
    `Priority: Won't (future phase — hardware integration out of scope for current release)`
